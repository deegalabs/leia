# Evidências

Regra do evento: **Entrega > Evidência > Prazo > Pontos.** Sem evidência publicada, o checkpoint não existe.

| Pasta | Entrega | Prazo | O que colocar |
|---|---|---|---|
| `01-canvas/` | Canvas | sáb 12h | PDF/imagem do canvas entregue; foto do canvas manuscrito |
| `02-internal-tests/` | V1 com testes internos | sáb 15h30 | `docs/INTERNAL-TESTS.md` preenchido, prints por caso, vídeo curto da V1 |
| `03-external-tests/` | V2 com testes externos | sáb 17h30 | planilha dos testes com leigos, depoimentos (com autorização), links dos posts com #hackathonoabpr |
| `04-product/` | Produto | dom 10h30 | instruções de teste para o auditor, dados de exemplo, relatório da bateria adversarial |
| `05-slides/` | Slides | dom 14h30 | deck do pitch de 2 minutos (PDF) e vídeo da demo |
| `extras/` | Pontos extras | ver prazos | prints dos posts (foto no banner até 10h de sáb; foto da equipe até 15h; live até 15h de dom) |

Nome dos arquivos: `AAAA-MM-DD-HHMM-descricao.ext`. Sem dados pessoais de clientes reais.
