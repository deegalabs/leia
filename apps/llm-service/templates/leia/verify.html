Verificação do registro

Esta página não contém nome, documento nem respostas. Só o que é preciso para conferir que o registro existe e não mudou.

Código (SHA-256 do JSON canônico):

{{ payload_hash }}

Registrado em: {{ payload.createdAt }} · Carimbo público: {{ 'OpenTimestamps presente' if ots_present else 'pendente' }} {% if ots_present %}· baixar prova .ots{% endif %}

JSON canônico (copie exatamente como está):

{{ canonical }}

Como conferir

  1. Salve o JSON canônico acima em um arquivo, sem espaços nem quebras de linha extras.
  2. Rode sha256sum arquivo.json (ou openssl dgst -sha256 arquivo.json).
  3. Compare com o código acima. Se for igual, o registro não mudou.
  4. Com a prova .ots: ots verify arquivo.json.ots mostra a data e hora carimbadas na rede pública.
