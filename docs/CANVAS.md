# Canvas (Entrega 1, 12/09/2026, 12h)

Transcrição do canvas manuscrito entregue (StartSe AI Canvas, 7 blocos). Arquivo em [../evidence/01-canvas/](../evidence/01-canvas/).

| Bloco | Conteúdo entregue |
|---|---|
| 1. Problema | Dados abertos e expostos; informações pessoais; falta de conhecimento; golpe do falso advogado. |
| 3. Como resolver sem IA | Pesquisar no Google sobre o conteúdo do documento e escritórios de advocacia especializados no tema. |
| 4. Como resolver com IA | Inserir o documento no ChatGPT; inserir seus dados pessoais e perguntar o que fazer. |
| 5. Para quem | Cidadão; advogados; OAB; órgãos públicos. |
| 6. Dados | Documento validado, cláusulas, perguntas, respostas, dados pessoais protegidos, somente o hash é ancorado. |
| 7. Ferramentas | IA conversacional, RAG, texto, painel do advogado, assistente, assinatura eletrônica, banco de dados criptografado, SHA-256, carimbo temporal. |
| 2. Indicadores de sucesso | Compreensão demonstrada, redução de dúvidas, evitar retrabalho, satisfação, integridade de registro, usabilidade, confiabilidade, supervisão humana. |

Leitura: os blocos 3 e 4 descrevem o comportamento atual do cidadão (busca genérica; documento e dados pessoais
colados em um chatbot público), que é a origem do problema do bloco 1. A solução proposta está em
[POSITIONING.md](POSITIONING.md) e [ARCHITECTURE.md](ARCHITECTURE.md); os blocos 6 e 7 já descrevem o modelo de
dados e as ferramentas dela.
